Privacy Policy for domus-backup

Effective Date: November 24, 2026

Overview

domus-backup is a personal, single-user backup utility. This Privacy Policy describes how the application interacts with user data and third-party services.

Data Collection and Storage

  • Personal Data Collected: None. The application does not collect, record, track, or transmit any personal identifiable information, telemetry, or user analytics.
  • Client-Side Encryption: All backup files are encrypted client-side prior to transfer. Plaintext file contents are never transmitted across the network.
  • Third-Party Sharing: None. User data is never sold, shared, monetized, or transferred to any third parties or external servers.

Google Drive Access and Scopes

domus-backup requests only the https://www.googleapis.com/auth/drive.file scope. Under this scope:

  • The application can only read, write, create, and modify files and folders that were specifically created by domus-backup or opened with it.
  • The application does not have access to any other files or folders in your Google Drive.
  • Data is stored strictly in a dedicated user-designated folder within the user's own Google Drive account.

Google API Limited Use Disclosure

domus-backup's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
